# Admin desk: one operational overview

`/desk` now opens the editor-only platform overview. Daily navigation is shared
by the dashboard, Projects, Agent team and the publication queue:

1. Editorial desk — platform checks, attention, saved drafts and current work.
2. Projects — dossier contributions, assignments and versioned private previews.
3. Agent team — configuration, specialties, models and instructions.
4. Review & publish — existing publication workflow at `/desk?tab=workspace`.

Evidence tools, contributor accounts, claimed work, activity, history, prompts,
analytics and design reference are under More administration. Existing query
links are preserved. The account menu leads with the three editorial destinations
for the admin; personal contributor tools remain in a collapsible group.

The overview performs independent, read-only observations of the canonical data
plane and scoped Limen model catalogue. A failed section remains unavailable,
not an empty queue. Configuration does not demonstrate execution; a task lease
does not demonstrate worker health; catalogue access does not demonstrate model
generation. Worker health is explicitly unverified until runtime observations
exist. Published voyages derive from the edition's ATLAS registry, not approved
submission status. Saved drafts link to immutable result IDs; each preview is
the authority for that version's review, not the mutable pipeline projection.

The default dashboard skips loading legacy administration endpoints. The
publication queue and advanced pages retain their existing data access and
permissions. No migration, worker startup or content publication is included.
